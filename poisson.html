Section 2. Log transform and re-check (~8 min)

Because some feeders have zero visits, we will use log(visits + 1) instead of log(visits).

Transform the response and plot the relationship

poisson_data$log_visits <- log(poisson_data$visits + 1)

ggplot(poisson_data, aes(x = sucrose_pct, y = log_visits)) +
  geom_point(alpha = 0.7, color = "darkblue") +
  stat_smooth(method = "lm", formula = y ~ x, se = TRUE, color = "black") +
  theme_classic() +
  labs(
    x = "Sucrose concentration (%)",
    y = "ln(visits + 1)"
  )

Fit a linear model to the transformed response

log_model <- lm(log_visits ~ sucrose_pct, data = poisson_data)
summary(log_model)
par(mfrow = c(1, 2))

qqnorm(resid(log_model), main = "Normal Q-Q Plot (Log Response)")
qqline(resid(log_model), col = "blue")

plot(
  fitted(log_model), resid(log_model),
  xlab = "Fitted values", ylab = "Residuals",
  main = "Residuals vs Fitted (Log Response)"
)
abline(h = 0, col = "blue", lty = 2)
par(mfrow = c(1, 1))

The log transformation often helps because the relationship looks closer to linear and the spread is more stable. A Poisson GLM also uses a log link function, but it models the mean count with that link while keeping a Poisson distribution for the response on the original count scale.

Section 3. Fit the Poisson GLM (~8 min)

Now I will fit the model that matches the count response.

poisson_model <- glm(
  visits ~ sucrose_pct,
  family = poisson(link = "log"),
  data = poisson_data
)

summary(poisson_model)

The slope in this model is on the log scale. If sucrose_pct increases by one unit, the expected log mean count changes by the slope estimate. On the original scale, the expected mean count is multiplied by exp(beta1) for a one-unit increase in sucrose concentration.

Compare the transformed lm() and the Poisson glm()

coef(summary(log_model))
coef(summary(poisson_model))

ANOVA

With one predictor, the test is straightforward. I will use Type II here to keep the workflow consistent with the car package tools we will use later.

Anova(poisson_model, type = "II")

Prediction and plotting on the original count scale

new_data <- data.frame(
  sucrose_pct = seq(
    min(poisson_data$sucrose_pct),
    max(poisson_data$sucrose_pct),
    length.out = 200
  )
)

pred_link <- predict(poisson_model, newdata = new_data, type = "link", se.fit = TRUE)

new_data$fit <- exp(pred_link$fit)
new_data$lwr <- exp(pred_link$fit - 1.96 * pred_link$se.fit)
new_data$upr <- exp(pred_link$fit + 1.96 * pred_link$se.fit)
ggplot(poisson_data, aes(x = sucrose_pct, y = visits)) +
  geom_point(alpha = 0.65, color = "darkgreen") +
  geom_ribbon(
    data = new_data,
    aes(x = sucrose_pct, y = fit, ymin = lwr, ymax = upr),
    inherit.aes = FALSE,
    alpha = 0.2,
    fill = "skyblue3"
  ) +
  geom_line(
    data = new_data,
    aes(x = sucrose_pct, y = fit),
    inherit.aes = FALSE,
    color = "navy",
    linewidth = 1
  ) +
  theme_classic() +
  labs(
    x = "Sucrose concentration (%)",
    y = "Expected hummingbird visits"
  )
